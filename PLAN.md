## Plano técnico de implementação

### Estratégia — reconstrução do zero

A implementação deve ser tratada como um **greenfield rebuild** da landing page, não como uma atualização incremental da página atual.

A base atual tem componentes, carrosséis, textos e estética que não combinam com o novo objetivo premium/luxo. Portanto, será mais simples, limpo e previsível descartar a landing page existente e reconstruir a experiência do zero.

Manter apenas:

- Estrutura do projeto Next.js
- Logo atual da Cerasos
- Dados de contato existentes
- Assets úteis, se fizerem sentido visualmente
- Componentes UI genéricos apenas quando ajudarem

Descartar ou deixar de usar:

- Hero atual com carrossel
- Seção atual de serviços genéricos
- Seção atual de contato
- Estética azul/ciano atual
- Textos genéricos atuais
- Qualquer componente que atrapalhe a nova direção visual

Abordagem:

- Reescrever `page.tsx` com uma one-page totalmente nova
- Reescrever header, footer e estilos globais
- Criar novos componentes específicos para a nova landing
- Reaproveitar apenas o logo e os dados de contato
- Evitar carrosséis obrigatórios; priorizar layout editorial premium e performance
- Criar dados estruturados em arrays para setores, mockups e benefícios
- Manter componentes bem organizados e fáceis de editar

### Arquivos prováveis

- `src/app/layout.tsx`
  - Atualizar metadata SEO

  - Garantir `lang="pt-BR"`

  - Reescrever a landing page completa

  - Atualizar tokens de cor
